Generates the recommended Ansible layout (inventories/, group_vars/, roles/, playbooks/site.yml).

Optionally add your first host to the production inventory. Leave the name blank to skip.

This reads from the filesystem of the machine the app runs on (browsers can't access your client filesystem). The directory is copied into the GUI's project store with a fresh git history; your original is untouched.

If your playbooks live on a different machine (e.g. your laptop), use one of: Clone from git (push the repo somewhere reachable), Upload .zip (zip the folder and drop it here), or rsync the folder onto this server and point at the result.

To reach paths outside /data, bind-mount them in docker-compose.yml — see the commented /import/* examples.

For SSH URLs (git@host:owner/repo.git) bind-mount your host SSH agent socket in docker-compose.yml (see the commented SSH_AUTH_SOCK example). For private HTTPS use a personal access token in the token field — it is sent only for the clone and discarded after.
